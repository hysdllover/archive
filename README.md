## GitHub Pages 올리기
1. GitHub에서 새 저장소 생성 (Public).
2. 이 폴더의 모든 파일을 저장소 최상단에 업로드.
3. Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save.
4. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 접속.

### 아이폰·아이패드에 앱처럼 설치
Safari로 접속 → 공유 → **홈 화면에 추가**. 주소창 없이 전체화면으로 실행되고, 저장 공간이 훨씬 잘 유지됩니다.

공부 타이머가 돌아가는 동안에는 어느 탭에 있든 상단에 경과 시간이 표시되고, 그 칩을 누르면 플래너로 돌아갑니다.

## 저장과 백업
- 입력하는 즉시 기기 안(localStorage)에 **자동 저장**됩니다.
- 하루 한 번 **자동 스냅샷**이 최근 10일치 남아, 설정에서 그 날짜 상태로 되돌릴 수 있습니다.
- 기기 변경·Safari 데이터 삭제에는 스냅샷도 함께 사라집니다. **주 1회 설정 → 파일로 내보내기**로 JSON을 파일 앱(iCloud Drive)에 저장하세요. 아이폰에서 내보내고 아이패드에서 불러오면 기기 간 이동도 됩니다.
- 불러오기는 **병합**(기존 기록 유지, 없는 항목만 추가)과 **덮어쓰기** 중 고를 수 있습니다.

## 기능을 고치거나 추가할 때
기록(데이터)과 화면(코드)이 분리되어 있어, 코드를 바꿔도 기존 기록은 그대로 남습니다.

**새 탭 추가** — `js/views/새이름.js`를 만들고
```js
App.register({
  id:'review', label:'복습',
  icon:'<path d="..."/>',        // 24×24 stroke 아이콘
  render(){ return '<div class="card">...</div>'; },
  mount(root){ /* 클릭 이벤트 연결 */ },
  unmount(){ /* setInterval 정리 */ }
});
```
`hidden: true`를 넣으면 하단 탭바에 나오지 않습니다(설정 화면이 이 방식입니다).
`index.html`에서 `app.js` **위에** `<script src="js/views/새이름.js"></script>` 한 줄만 추가.

**새 데이터 추가** — `js/store.js`에서
1. `defaults()`에 키 추가 (예: `reviews: []`)
2. `App.SCHEMA`를 `2`로 올리고
3. `MIGRATIONS`에 `3: (d) => { d.reviews = []; return d; }` 추가 (현재 스키마는 v3)

기존 데이터가 자동으로 새 구조로 올라갑니다. **기존 키의 이름이나 의미는 바꾸지 말고 추가만** 하세요.

**색·글꼴 조정** — `css/style.css` 맨 위 `:root` 변수만 고치면 전체에 반영됩니다. (`--fs` 글자 크기, `--accent` 포인트색, `--r` 모서리)

## 인쇄
시간표 탭의 `인쇄 · PDF` 버튼 → 아이패드에서는 공유 시트에서 **PDF로 저장**. A4 세로 기준으로 탭바·버튼이 빠지고 표만 깔끔하게 출력됩니다.

## 파일 구조
```
index.html          화면 뼈대 + 스크립트 로드 순서
manifest.json       홈 화면 설치 설정
css/style.css       디자인 토큰 + 인쇄 스타일
js/store.js         데이터·자동저장·스냅샷·마이그레이션
js/ui.js            시트/토스트/차트/포맷 유틸
js/app.js           탭·라우팅·렌더
js/views/*.js       화면별 기능 (파일 하나 = 탭 하나)
```
